# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues or discussions.**

Report privately using GitHub's **[Report a vulnerability](../../security/advisories/new)** form (Security tab → Advisories). Alternatively, contact us via <https://velovane.cc/support.html> and mark the message "Security".

Please include:

- Affected platform (iOS / Android / web) and app version
- Steps to reproduce and the potential impact
- Any proof-of-concept, if available

We aim to acknowledge reports within 3 business days and will keep you updated until resolved.

## Supported versions

Only the latest version available on the App Store, Google Play and the web is supported with security fixes.
