# Contributing

Thanks for helping improve Velo Vane!

The app's source code is not public, so **pull requests are not accepted** here. You can contribute by:

- Filing clear, reproducible [bug reports](../../issues/new?template=bug_report.yml)
- Proposing [features](../../issues/new?template=feature_request.yml) with the problem you're trying to solve
- Answering questions in [Discussions](../../discussions)
- Reacting 👍 to existing issues you care about — we use this to prioritise

Please search before posting and follow the [Code of Conduct](CODE_OF_CONDUCT.md).
