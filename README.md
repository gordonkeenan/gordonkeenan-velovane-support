# Velo Vane — Support & Issue Tracker

Public support hub for **[Velo Vane](https://velovane.cc/)**, route-specific weather for cyclists on iOS, Android and the web.

> This repository contains **no application source code**. It exists only for bug reports, feature requests and community support.

## Get help

| I want to… | Go to |
|---|---|
| Find a quick answer | [FAQ](https://velovane.cc/faq.html) |
| Report a bug | [New bug report](../../issues/new?template=bug_report.yml) |
| Suggest a feature | [New feature request](../../issues/new?template=feature_request.yml) |
| Ask a question or share an idea | [Discussions](../../discussions) |
| Get help with billing or a subscription | [Support page](https://velovane.cc/support.html) |
| Report a security issue | See [SECURITY.md](SECURITY.md) — **do not open a public issue** |

Before opening an issue, please [search existing issues](../../issues?q=is%3Aissue) to avoid duplicates. Add a 👍 reaction to an existing issue instead of commenting "+1".

## Protect your privacy

Issues here are **public**. Please do not post:

- Your home, work or other saved addresses, or screenshots of maps showing them
- Email addresses, receipts, order IDs or payment details
- Exported route files (GPX/FIT/TCX) that reveal where you live or work

For anything personal, use the [support page](https://velovane.cc/support.html) instead.

## How issues are handled

1. New issues are labelled `needs-triage`.
2. We confirm, then label by type and platform (`ios`, `android`, `web`).
3. Issues needing more information get `needs-info` and may be closed if there's no reply after 14 days.
4. Fixes ship in app updates; the issue is closed with a note of the version it shipped in.
